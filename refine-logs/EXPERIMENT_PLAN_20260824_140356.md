# Experiment Plan：统一自然语言指令多语言 SLT

**Problem**：现有高分 SLT 系统通常针对固定数据集与固定目标语言优化，专用 mBART decoder 在单一翻译任务上具有优势。我们的 Qwen 架构绝对单语性能较低，但 Mono-Qwen 与 Unified-Instruct 性能几乎一致。本研究需要证明：在不显著损害自身翻译能力的情况下，一个 checkpoint 可以通过自然语言指令可靠地控制多个目标语言。

**Method Thesis**：多语言自然语言指令控制可以近乎零成本地加入统一 SLT 模型；其价值体现在同一 checkpoint 的目标语言可控性和对新 prompt 表达的泛化，而非固定目标 benchmark 的 SOTA 排名。

**Date**：2026-08-24

## Claim Map

| Claim | 为什么重要 | 最低可信证据 | Linked Blocks |
|---|---|---|---|
| C1（主张）：一个 Unified-Instruct checkpoint 能覆盖多个目标语言，且相对同架构 Mono-Qwen 几乎无性能损失 | 证明新增能力不是用明显翻译退化换来的 | DE/EN/ZH 分别比较 Mono-Qwen 与 Unified-Instruct；报告差值、置信区间和最差语言 | B1 |
| C2（主张）：模型依据自然语言指令语义控制目标语言，而不是把固定 prompt 或 prompt 所用语言当作 language ID | 证明“instructed”真实成立 | seen、held-out paraphrase、cross-lingual instruction、remove/conflict controls；输出语言与语义质量均稳定 | B2、B3 |
| Anti-claim：模型只是较弱翻译器外加 prompt 包装 | 必须正视绝对质量 | 紧凑 SOTA/reference 表；明确专用系统与统一系统能力不匹配；同时报告翻译质量和能力范围 | B4 |

## Paper Storyline

### 主文必须证明

1. `Mono-Qwen ≈ Unified-Instruct`：统一、多语言、自然语言控制的边际性能成本很低。
2. 改变同一视频的目标语言指令会可靠改变输出语言，同时尽量保持语义一致。
3. 对训练未见的 prompt 改写仍有效，并且指令语言和目标语言可以解耦。
4. 模型绝对翻译质量虽非固定目标 SOTA，但仍处于可用范围；传统 SOTA 仅作为质量锚点。

### Appendix 支撑

- 完整 prompt bank 与 train/held-out 划分。
- 每语言、视频长度、文本长度分桶结果。
- 输出语言检测器校准、人工错误分类、定性样例。
- Visual adapter、CTC 和其他工程消融；这些不是论文主线。

### 明确不声称

- 不声称单语言 SOTA。
- 不声称 zero-shot target-language translation；目标语言在训练中出现过。
- 不声称 mBART 系统“不理解视频”或其得分完全来自 decoder。
- 不声称 held-out prompt 等同于 held-out language；它是 unseen-instruction generalization。

## Experimental Protocol

### 数据单位与公平性

- 同一手语视频具有 DE/EN/ZH 等目标文本时，固定视频 split，禁止同一视频跨 train/test。
- 明确多语言文本是人工标注还是从原始目标机器翻译生成；后者统一称 synthetic multilingual supervision。
- Mono-Qwen 与 Unified 模型使用相同视觉输入、视觉 backbone、adapter、LLM 初始化、decode 和 metric。
- 同时报告两种训练预算：
  - **Equal steps**：模型优化步数相同；
  - **Equal per-language exposure**：每种语言被看到的次数相同。
  主结论优先采用 equal per-language exposure，equal steps 作为效率补充。

### Prompt split

- `Train prompts`：训练中随机采样；覆盖多种措辞和多种 instruction language。
- `Seen-test prompts`：从训练模板集合采样，测常规表现。
- `Held-out paraphrases`：语义等价但模板在训练中从未出现；模型和超参数冻结后才使用。
- `Cross-lingual prompts`：instruction language 与 requested target language 正交组合，例如中文指令要求德语输出。
- `Adversarial controls`：remove instruction、错误目标语言、冲突要求。

## Experiment Blocks

### B0：Sanity 与评测冻结

- **Claim tested**：所有后续差异不是数据、decode 或语言检测器错误。
- **Runs**：重复评测现有 Mono/Unified checkpoint；200–500 样本过拟合；人工核对每语言 50 个输出。
- **Metrics**：BLEU-4、ROUGE-L、COMET/XCOMET（若语言受支持）、chrF、output-language accuracy、长度比。
- **语言检测**：在全部 reference 上运行；若正确率低于 99%，不能作为主要控制指标，需人工标注或更可靠 detector。
- **Success criterion**：重复评测一致；小集可过拟合；输出/参考清洗规则冻结。
- **Failure interpretation**：停止正式实验，先修 pipeline。
- **Target**：内部 assurance，不占主表。
- **Priority**：MUST-RUN。

### B1：Unified Capability at Near-Zero Performance Cost

- **Claim tested**：统一 instruction 模型相对自身单语模型几乎无损。
- **Compared systems**：
  1. Mono-Qwen-DE；
  2. Mono-Qwen-EN；
  3. Mono-Qwen-ZH；
  4. Unified-LID（简单 language ID 控制）；
  5. Unified-FixedPrompt；
  6. Unified-DiversePrompt（最终模型）。
- **Metrics**：逐语言 BLEU-4、ROUGE-L、chrF、COMET/XCOMET；macro average、worst-language score。
- **关键派生量**：
  - `Delta_l = UnifiedInstruct_l - Mono_l`；
  - `Retention_l = UnifiedInstruct_l / Mono_l × 100%`；
  - `InstructionCost = UnifiedInstruct - UnifiedLID`；
  - checkpoint 数、总存储、总训练成本。
- **Seeds**：主比较 Mono-Qwen、Unified-LID、Unified-DiversePrompt 建议 3 seeds；FixedPrompt 可先 1 seed，只有结论敏感时补 seed。
- **Success criterion**：
  - 平均绝对差异落在预注册等价区间，例如 BLEU-4 `[-1.0, +1.0]`；
  - 或 macro retention ≥95%；
  - 任一语言不存在明显崩溃；
  - 最好使用 paired bootstrap CI 或 seed CI 支持“no meaningful degradation”，不能仅凭不显著差异宣称等价。
- **Failure interpretation**：若 Unified-LID 与 Mono 接近但 Instruct 下降，问题是 instruction 训练；若 Unified-LID 已下降，问题是 multilingual interference。
- **Table target**：Main Table 1（论文最重要的性能表）。
- **Priority**：MUST-RUN。

### B2：Seen 与 Held-out Prompt Generalization

- **Claim tested**：模型不是记忆几条固定 prompt。
- **Compared conditions**：canonical seen prompt、random seen prompt、held-out same-language paraphrase、held-out multilingual paraphrase。
- **冻结要求**：held-out prompt 在训练、validation 和超参数选择中均不可见。
- **采样协议**：每个 test video 至少使用 3–5 个 prompt；同一视频各 prompt 结果配对比较。
- **Metrics**：
  - output-language accuracy；
  - BLEU/COMET 相对 canonical prompt 的下降；
  - prompt robustness：同一视频不同同义 prompt 输出的 pairwise semantic similarity；
  - failure rate：空输出、错误语言、拒答、复述指令。
- **Success criterion**：held-out prompt 输出语言准确率接近 seen（建议差距 ≤2–3 points），翻译语义指标下降有限（建议 ≤3% relative）。
- **Failure interpretation**：若 seen 好、held-out 差，只能声称 prompt-conditioned，不应声称 natural-language instruction generalization。
- **Table target**：Main Table 2。
- **Priority**：MUST-RUN。

### B3：Instruction Semantics 与语言捷径排除

- **Claim tested**：目标语言由指令内容决定，而不是由 instruction language 决定。
- **核心矩阵**：每种 instruction language × 每种 target language 全交叉测试。

| Instruction language → Target | DE | EN | ZH |
|---|---:|---:|---:|
| German instruction | — | — | — |
| English instruction | — | — | — |
| Chinese instruction | — | — | — |

- **每个 cell 报告**：output-language accuracy + translation semantic score。
- **控制组**：
  1. remove instruction；
  2. 仅保留目标语言名称；
  3. conflicting instruction，例如前半句要求英语、后半句要求德语；
  4. 同一视频切换 DE→EN→ZH，检查输出语义一致性。
- **Success criterion**：非对角 cell 与对角 cell 差距小；模型根据 requested target 而非 instruction language 输出；remove/conflict 控制产生可解释变化。
- **Failure interpretation**：若只有对角 cell 好，模型使用 prompt language 作为隐式 language ID。
- **Figure target**：Main Figure 2 heatmap + 一个同视频三语言 qualitative example。
- **Priority**：MUST-RUN。

### B4：传统 SOTA / Specialist Quality Anchor

- **Claim tested**：统一模型虽不追求固定目标 SOTA，但翻译质量仍具有实际意义。
- **Baseline families（最多三类）**：
  1. 代表性传统/预训练 gloss-free SLT；
  2. LLM-based specialist，如 SpaMo；
  3. MLLM-description specialist，如 MMSLT。
- **表格规则**：
  - `Reported` 与 `Reproduced` 分开；
  - 标出 decoder、目标语言、# checkpoints、额外监督/数据、是否离线 MLLM preprocessing、是否自然语言控制；
  - 只在相同数据、split、监督和 metric 时直接比较数值；否则加 `†` 并写明仅作 reference。
- **Metrics**：标准 BLEU-4、ROUGE-L；不要用自定义综合分数重排 SOTA。
- **Success criterion**：没有硬性胜出要求；目标是透明定位质量差距，并展示能力不匹配。
- **Failure interpretation**：若质量过低到人工判断不可用，则 instruction claim 仍可能成立，但系统贡献会显著变弱，必须在 limitation 中说明。
- **Table target**：Main Table 3，保持紧凑；完整列表放 appendix。
- **Priority**：MUST-RUN，但不需要为每个 SOTA 重新训练。

## Run Order and Milestones

| Milestone | Goal | Runs | Decision Gate | Cost | Risk |
|---|---|---:|---|---|---|
| M0 | 冻结评测 | 评测重跑 + 小集 overfit | metric、language detector 和输出清洗可信 | 很低 | 评测假差异 |
| M1 | 证实近零成本 | 现有 Mono/Unified 先统一重评；缺失的 LID/Fixed 各 1 seed | Mono≈Unified 是否成立 | 中 | 比较预算不公平 |
| M2 | 主结果补 seeds | Mono、LID、最终 Instruct 补至 3 seeds | 等价区间/retention 稳定 | 高 | seed 方差 |
| M3 | Prompt 泛化 | 无需训练：seen/held-out/cross-lingual 全矩阵 | 指令语义而非捷径 | 低 | prompt 泄漏 |
| M4 | SOTA anchor | 汇总同协议文献，必要时只复现一个代表 baseline | 质量定位透明 | 低至中 | 不同协议误导 |
| M5 | Qualitative/failure | 同视频多语言、失败类型、视觉扰动 | 展示能力与边界 | 低 | cherry-picking |

## Compute and Data Budget

- **最省预算版本**：复用已有 Mono/Unified checkpoints；新增 Unified-LID 与 FixedPrompt 各 1 seed；prompt 实验均只推理。
- **论文稳健版本**：Mono、Unified-LID、Unified-DiversePrompt 各 3 seeds。若已有 Mono 多语言分别训练，则只补缺失 seed。
- **不建议**：为追逐每个外部 SOTA 全部复现；它们不是主 claim 的控制变量。
- **最大数据工作**：构建、去重并冻结 prompt bank；确保 instruction-language × target-language 平衡。

## Risks and Mitigations

- **风险：Mono 与 Unified “差不多”只是单 seed 偶然。**
  - 使用等价区间、paired bootstrap 和 3 seeds；报告差值而不只报告两列分数。
- **风险：自然语言 prompt 只是 language ID。**
  - held-out paraphrase、cross-lingual matrix、remove/conflict controls。
- **风险：Qwen 绝对性能落后 mBART specialist。**
  - 完整报告差距；把 mBART 作为 fixed-target quality anchor；主 claim 限定为能力与近零边际成本。
- **风险：合成翻译使多语言结果过于容易。**
  - 披露生成方式；检查跨语言语义一致性；若可行，人工核验固定 test subset。
- **风险：instruction 指标高但视频被忽略。**
  - 加 normal/zero/wrong/shuffled video；要求语义质量随错误视频显著下降，而语言控制仍服从指令。
